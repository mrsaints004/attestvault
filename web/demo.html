04 — Verification ledger

Confirmed vs. still pending

Same standard this whole project holds itself to: nothing gets marked solid unless it traces to a real source.

Confirmed

  • Single-tx proof flow matches the official usc-testnet-bridge-examples/loan-flow reference pattern.
  • Batch ABI shape (heights[], txs[], merkleProofs[], shared ContinuityProof) pulled from the real block_prover.json shipped in the published SDK.
  • Precompile address and event-signature log decoding match the reference contract exactly.

Pending a live run

  • forge build has not been executed against these contracts yet.
  • executeBatch calling the precompile's batch overload from inside a contract is unverified.
  • Exact published version of @gluwa/usc-contracts for EvmV1Decoder is unconfirmed.
  • Chain 2's real source-chain key on CC3 Testnet is unconfirmed with the Creditcoin team.
